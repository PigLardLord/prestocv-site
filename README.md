# PrestoCV site

The support and privacy pages of PrestoCV, the free CV and resume maker for iPhone and iPad, served at <https://prestocv.app>.

- `index.html`: support, with the contact address and answers to common questions.
- `privacy.html`: the privacy policy.
- `source.html`: where the app's code is published, and under which licence.

The app's code lives in its own repository, <https://github.com/PigLardLord/PrestoCV>. "PrestoCV" and its icon are trademarks of Giovanni Trovato.
